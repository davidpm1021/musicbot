## Project Overview

D&D Music Bot for Discord - plays locally hosted audio files (not YouTube/streaming) in Discord voice channels via simple text commands. DMs trigger ambient/battle music during tabletop sessions without managing JSON files directly.

## Build and Development Commands

```bash
# Install dependencies
npm install

# Run the bot
npm start
# or
node src/index.js

# Regenerate track catalog from folder structure
python build_tracks.py

# Reload tracks without restarting bot (in Discord)
!reloadtracks
```

## Architecture

### Core Components

**Bot Entry Point** (`src/index.js`)
- discord.js v14 client initialization
- Message event listeners for prefix commands (!play, !stop, !search, !reloadtracks)
- Graceful shutdown handling

**Audio Pipeline**
- FFmpeg (via ffmpeg-static) converts audio files → PCM
- PCM piped to Discord via @discordjs/voice AudioPlayer
- @discordjs/opus for encoding
- Supports: .mp3, .flac, .wav, .ogg, .m4a

**Track Catalog** (`tracks.json`)
- Auto-generated by `build_tracks.py` from folder structure
- In-memory cache, hot-reloadable without bot restart
- Schema:
```json
{
  "id": "super-battle-theme",        // URL-safe slug for !play command
  "name": "Super Battle Theme",       // Display name from filename
  "file": "D:\\DND-Music\\battle\\intense\\Super Battle Theme.mp3",
  "tags": ["battle", "intense"]       // Derived from subfolder hierarchy
}
```

**Folder-Driven Tagging**
```
DND-Music/
  battle/
    intense/     → tags: ["battle", "intense"]
    easy/        → tags: ["battle", "easy"]
  ambience/
    calm/        → tags: ["ambience", "calm"]
```

### Data Flow

```
!play <id> → Validate user in voice channel
           → Lookup track in catalog
           → Verify file exists on disk
           → FFmpeg loads file → PCM stream
           → Pipe to @discordjs/voice AudioPlayer
           → Audio plays in Discord voice channel
```

## Configuration

**.env file** (required):
```
DISCORD_TOKEN=your_bot_token
MUSIC_PATH=D:\DND-Music
TRACKS_FILE=./tracks.json
```

Must support Windows paths with spaces.

## Technology Stack

- **Runtime**: Node.js LTS (18.x or 20.x)
- **Platform**: Windows (dev on Win10 Pro, prod on Windows Server/HP EliteDesk)
- **Core deps**: discord.js v14, @discordjs/voice, @discordjs/opus, ffmpeg-static, dotenv
- **Indexer**: Python 3.x (build_tracks.py)

## Discord Requirements

**Required Intents** (enable in Developer Portal):
- Message Content Intent (for prefix commands)
- Guild Voice States (for joining voice channels)

**Required Bot Permissions**:
- Connect, Speak, Use Voice Activity (voice)
- Read Messages/View Channels, Send Messages, Embed Links, Read Message History (text)

## Key Constraints

- Local files only (no streaming services)
- Prefix commands only (no slash commands)
- No queues, playlists, volume control, or crossfades in v1
- Bot must recover gracefully from voice disconnections, missing files, catalog errors
- Track catalog auto-generated from folder structure (DM never edits JSON)
